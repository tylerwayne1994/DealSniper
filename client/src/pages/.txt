US County Parcel Boundary REST API Endpoints

A comprehensive reference of publicly accessible ArcGIS REST API and GeoJSON endpoints for parcel/property boundary data across the United States. All endpoints listed are publicly accessible (no authentication required) unless noted otherwise.

How to query any endpoint: Append /query?where=1%3D1&outFields=*&geometry=<lon,lat>&geometryType=esriGeometryPoint&inSR=4326&spatialRel=esriSpatialRelIntersects&outSR=4326&f=geojson to the base URL to retrieve the parcel polygon at a given coordinate.

How to Use These Endpoints in Leaflet

To fetch a parcel polygon for a specific lat/lon coordinate and render it on a Leaflet map:

JavaScript


async function getParcelPolygon(lat, lon, featureServerUrl) {
  const query = new URLSearchParams({
    where: '1=1',
    geometry: `${lon},${lat}`,
    geometryType: 'esriGeometryPoint',
    inSR: '4326',
    spatialRel: 'esriSpatialRelIntersects',
    outFields: '*',
    outSR: '4326',
    f: 'geojson'
  });
  const res = await fetch(`${featureServerUrl}/query?${query}`);
  const geojson = await res.json();
  if (geojson.features && geojson.features.length > 0) {
    L.geoJSON(geojson, {
      style: { color: '#ff7800', weight: 2, fillOpacity: 0.3 }
    }).addTo(map);
  }
}
